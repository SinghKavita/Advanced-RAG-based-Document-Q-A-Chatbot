# This project implements an advanced Retrieval-Augmented Generation (RAG) system using LangChain, OpenAI GPT-4, Chroma, and Streamlit to enable intelligent document retrieval and provide product insights. Key features include:

Dynamic document indexing and management with Chroma for high-performance vector storage.

LangChain for seamless integration of retrieval and generation pipelines, including document context-aware responses.

Real-time querying and interactive user experiences powered by Streamlit for easy integration and visualization.

A comprehensive backend system built with FastAPI, including endpoints for uploading, indexing, listing, and deleting documents.

Utilization of SQLite for application logs and document storage, enabling efficient record-keeping and history management.
